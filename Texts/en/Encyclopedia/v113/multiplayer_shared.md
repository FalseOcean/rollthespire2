# Shared Party Conditions: What Is Set Once or Per Player?

If you want a seed with Morphic Grove, set the event queue condition once for the party. If you want two players to transform cards into particular results, set an outcome for each of those players. The queue gives you the order of the candidates. What you actually encounter at a question mark depends on what happens when you reach it. See [[event-appearance]].

Imagine two Ironclads both transforming a Strike and a Defend at Morphic Grove. The Grove is a shared event, so both players' event streams start in the same place. If they transform the cards in the same order and have the same candidate pools, they can get the same two cards. Ordinary personal events factor in the player seat when setting the starting point. With New Leaf, each player draws from their own transformation stream too.

Relics can also change something the party shares. When a player gets a relic from a Capsule, that relic is removed from the shared treasure bag. The players have their own random streams, but this change to the bag can affect what appears in a later chest.

In the event picker, “Shared” refers to the pool of events shared across Acts. It is separate from voting together on an event option.

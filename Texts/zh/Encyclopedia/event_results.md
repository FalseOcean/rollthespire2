# 事件结果：当前能筛选什么？

很多事件有各自独立的 Event 随机流，因此还没遇到事件，就能预测、筛选其中的一些结果。这让我能提供更多有用的信息，而不必先还原整条游玩路线。各类结果仍按自己的规则计算，并非事件里的每一种随机结果都由同一条流决定。

| 事件 | 当前筛选内容 |
| --- | --- |
| 色彩哲学家 | 最初提供的角色颜色是否包含目标角色 |
| 假商人 | 六件库存中是否包含指定假遗物，不限定商品位置 |
| 垃圾堆 | 取得卡牌或取得遗物的指定结果 |
| 审判 | 接受审判后抽到的案件类型 |
| 造卡工坊 | 提供的卡牌类型，以及选择该类型后可选的附加效果 |

前三种的候选和概率见 [[event-stable-results|稳定事件结果]]。审判的装饰性编号不属于案件预测。

变牌结果也可以筛选：共生体、混沌芳香、低语空谷各一次，变形灵林谷与审判对应选项各两次。游戏允许变化合法的非初始牌，但为了计算、判断和输入简便，RT2 当前按变化初始牌的约定计算；其中也包括角色专属初始牌，不必固定选第一张初始打击。具体内容见 [[event-transform-results|事件变牌]]，多个来源的合计目标见 [[transform|变牌组合]]。

这里列的是当前提供的结果；例如无尽传送带尚未作为正式事件筛选开放。队列信息见 [[event-appearance|事件出现性]]，局内工具见 [[crystal-sphere|水晶球]]。

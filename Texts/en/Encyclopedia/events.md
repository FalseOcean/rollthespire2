# Events: Queues and Outcomes

RT2 provides information about each Act's event queue and filters for some outcomes within events. The queue helps you find events of interest; outcome conditions express what you want to obtain from them.

If you want the opening question marks to become event rooms, the Events page can also require the first one, first two, or first three question marks in Act 1 all to be events. This does not guarantee a particular event; see [[event-appearance|Event appearance]] for the premises and distinction.

See [[event-appearance|Event appearance]] for how to read queue positions, and [[event-results|Event outcomes]] for the current outcome directory. Transformation target assumptions are explained in [[event-transform-results|Event transformations]]. To combine results from multiple sources, see [[transform|Combined transformations]].

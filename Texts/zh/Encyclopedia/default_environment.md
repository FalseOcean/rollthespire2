# 默认环境

默认环境是**原版、单人、官方 Epoch 全部解锁**。幕与遭遇的发现状态是另外的输入，不包含在这里的“全解锁”中。

在这个环境下，你明确表达筛选需求，并遵守 RT2 事先说明的操作约定；RT2 承诺已确认结果会满足这些需求。各筛种页下面的解释会说明约定为何必要、哪些选择会影响结果，以及筛选确认了什么。

确认来自 RT2 的独立模型检查。程序中的 Exact 不表示调用真实游戏完整执行一局。正常检查也可能因实现缺口等原因交付未确认候选，包括默认环境中的候选；未知不等于已经不匹配，也不能算作确认满足。未确认候选可以收藏，并保留其未确认状态。

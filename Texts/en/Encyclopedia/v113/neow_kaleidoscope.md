# What Is {{relic:KALEIDOSCOPE}} Generation Order Useful For?

If you want to start with a specific Rare card from another character enchanted with Glam, let {{relic-icon:SILKEN_TRESS}} enchant the first group from {{relic-icon:KALEIDOSCOPE}}. When filtering seeds, put the target card **in Kaleidoscope's first group** and set Silken Tress as the other relic inside {{relic-icon:NEOWS_BONES}}.

Take Tress first, then Kaleidoscope. Tress gives Glam to the next card reward, so you can take the enchanted card from Kaleidoscope's first group. Both groups are generated in order before the rewards appear. Glam is already set by then, so you can open the second group first if you want to see what's in it.

See [[neow-offer]] for relic pickup order.

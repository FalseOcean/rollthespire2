# 事件结果：当前能筛选什么？

RT2 的事件结果条件假定对应事件已经发生。若还关心它是否进入前几个候选，需要另外设置事件候选条件；见 [[events|事件候选与结果]]。

## 事件自身就能确定的结果

这些结果使用事件自己的随机状态，不需要重建之前的普通战斗奖励或商店历史：

| 事件 | 当前筛选内容 |
| --- | --- |
| 色彩哲学家 | 最初提供的角色颜色是否包含目标角色 |
| 假商人 | 六件库存中是否包含指定假遗物，不限定商品位置 |
| 垃圾堆 | 取得卡牌或取得遗物分支的指定结果 |
| 审判 | 接受审判后抽到的案件类型 |
| 造卡工坊 | 提供的卡牌类型，以及选择该类型后可选的附加效果 |

前三种的固定候选和概率见 [[event-stable-results|稳定事件结果]]。审判的装饰性编号不属于案件预测；造卡工坊的不同类型是各自选择后的分支，不能把一条分支的随机消耗接到另一条上。

## 需要保留初始牌的变换

当前可筛选共生体、混沌芳香、低语空谷的单张初始牌变换，以及变形灵林谷、审判的两张初始牌变换。审判还要抽到对应案件并选择变牌分支。

这类预测要求到达时仍有合法的初始牌、选择约定分支，并维持预测时所用的变牌池与相关规则；不保证沿路线一定保住目标牌。具体操作前提见 [[event-transform-results|初始牌变换]]。

## 尚未提供的结果

无尽传送带等结果没有作为正式事件筛选开放。另一些奖励需要当前牌组、遗物袋、奖励随机进度或更长的行动历史；它们应逐项确认，不能笼统归为“无法预测”。水晶球的已发布功能单独见 [[crystal-sphere|水晶球]]。

如果预测与实际不同，先核对实际选项和该结果的前提；常见现象与短排错见 [[faq|FAQ]]。

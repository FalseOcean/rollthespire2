# RolltheSpire2

[English](README.md) | 简体中文

**找到想要的种子，再看看它能带来怎样的开局。**

RolltheSpire2（RT2）是一个面向《杀戮尖塔 2》的游戏内筛种与种子分析 Mod。你可以组合自己想要的条件，寻找符合要求的种子，并查看开局、奖励、地图等预测结果。

当前源码版本为 **1.3.5**，主要测试环境为 **Windows、游戏版本 0.111.0**。

## 可以做什么

- 按涅奥开局、商店、Boss、先古选项、事件、遗物、战斗奖励、地图条件和变牌组合筛种。
- 配置单人或 **2–4 人**筛种，分别设置个人条件和整桌共用条件。
- 查看指定种子的预测结果，预览地图、手绘路线，浏览某项指标并列最优的路线。
- 查看条件稀有度、搜索速度和找到**单个结果**的预计时间，在支持的条件下自动选择 CPU／GPU 搜索。
- 在种子库中收藏种子并填写标题、备注，复用筛种预设，查看持久保存的搜索历史；开发者推荐提供可直接使用的种子。
- 点击种子分析页中支持的事件查看预测结果，查阅重新组织的中英文游戏内百科。
- 遇到水晶球时，通过可选的局内入口读取当前事件状态、查看可共同取得的奖励并获取翻格指引，支持浮木重掷与可选的附魔目标。

## 下载与使用

[Steam 创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3755166888)

手动安装包与对应源码见 [GitHub Releases](https://github.com/FalseOcean/rollthespire2/releases)。旧版本将作为历史安装包保留，不再持续维护。

使用手动安装包时，将其中的 `RolltheSpire2` 文件夹放入游戏目录的 `mods` 文件夹。源码压缩包需要先编译才能使用。

1. 在游戏主菜单左上角打开 **RolltheSpire2**。
2. 选择单人或多人模式，设置角色、进阶和想要的筛选条件。
3. 开始搜索。找到结果后打开**种子分析**，也可以在分析页直接输入种子。

在设置中开启“局内预测入口”后，可预测单人或多人中的本地玩家水晶球事件。支持 3 次、6 次及剩余翻格次数，区分卡牌升级；“纳入附魔预测”和半透明遮罩为独立开关，均默认关闭。这是特定事件的局内功能，不等于预测任意当前局面或完整路线。

具体条件的规则与预测前提可以查阅游戏内百科。设置中可以切换语言与界面配色、调整历史数量和搜索起点、打开日志目录。历史默认保留最近 30 组查询，每组 30 个不同结果；预设关联的记录会保留。

## 多人与兼容范围

多人默认按全员全解锁处理，也可以主动读取实际大厅上下文。种子分析拥有独立的多人配置，涅奥选项按 **P1 → P2 → P3 → P4** 的顺序领取，界面显示的默认选项也参与预测，因此前面的选择可能影响后续玩家的结果。

多人暂不包含变牌组合筛选。地图筛选目前使用 CPU；手绘路线并不等于模拟完整一局中的所有操作。

游戏更新和修改游戏规则的 Mod 可能影响预测准确性。原版单人环境的测试最充分，多人、Mod 与非全解锁混合环境仍需更多验证。稀有度和 ETA 都是估算，复杂条件的估算可能尚不完整。

GPU 初始化失败时会显示具体阶段与原因，并提供显式重试。诊断改善不代表已兼容所有显卡、驱动和渲染后端。

未校验候选输出是独立选项，默认关闭。这类候选跳过最终 Exact 校验并明确标记，不保证满足全部条件；搜索结束后可单独校验。

在 RT2 顶部打开**问题反馈**，导出诊断 ZIP，并前往预填环境信息的 [GitHub Issue](https://github.com/FalseOcean/rollthespire2/issues/new) 页面。请补充问题描述与复现步骤，手动附上 ZIP 后提交；也可以复制反馈正文，发送邮件到 **rollthespire2@outlook.com**。

B站／创意工坊评论区更适合交流和简单问题，我不一定能在那里逐一深入排查 Bug。RT2 是兴趣维护的个人项目，无法保证每个问题都能及时回复或修复，感谢理解。

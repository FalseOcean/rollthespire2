# 事件变牌：为什么约定初始牌？

事件变牌和新叶一样，游戏中可以选择合法的非初始牌作为目标。只是目标来源不同，变牌池也可能不同。为了计算、判断和输入的简便，我暂时选择让 RT2 按变化初始牌来预测，避免为这些结果再要求一份详细的牌组输入。

这里的初始牌也包括角色专属的初始牌；在相同合法变牌池的前提下，不必固定选择第一张初始打击。到达事件时保留并选择约定的合法目标即可。

| 事件 | 当前提供的变牌结果 |
| --- | --- |
| 共生体 | 变牌选项的一张结果 |
| 混沌芳香 | 放手选项的一张结果 |
| 低语空谷 | 拥抱选项的一张结果 |
| 变形灵林谷 | 双变牌选项的两张结果 |
| 审判 | 无名者案件、无罪选项的两张结果 |

两张结果可以要求包含目标牌，也可以要求组成指定组合，不必固定结果先后。计算会保留各事件自身的必要随机步骤，例如低语空谷的金币计算、审判的案件抽取。

变形灵林谷的多人共享情况见 [[multiplayer-shared|多人共享条件]]。其它事件结果见 [[event-results|事件结果]]，多个变牌来源的合计需求见 [[transform|变牌组合]]。

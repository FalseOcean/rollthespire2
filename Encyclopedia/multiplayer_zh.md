# 多人：同一种子满足整桌条件

多人筛种要求**同一种子、同一局游戏同时满足所有玩家的条件**。幕变体、首领、标准地图和事件队列属于共同世界；涅奥选项、奖励、商店和普通事件结果等通常还要看各玩家的席位、角色与状态。

## 席位为什么重要

随机起点中的玩家位置是 P1 / P2 / P3 / P4，不是账号或角色名字。同一个角色换席位，个人结果可能改变。RT2 按配置的实际席位预测，不自动交换玩家寻找额外种子。

共同条件设置一次；个人条件分别设置。共同世界与事件结果的具体关系见 [[multiplayer-shared|多人共享条件]]。

## 开局领取顺序

RT2 为已配置的多人开局行为采用 **P1 → P2 → P3 → P4** 的顺序：一名玩家的约定行为完成后，再处理下一名；没有配置行为的玩家跳过。

如果领取涉及共享遗物袋，前面玩家拿走的遗物会影响后面的候选；如果使用持续随机状态，后续结果也要从实际推进后的状态继续。预测页要求的玩家顺序和骨骰内部领取顺序应当照做。

这个顺序不是所有多人事件的普遍规则。例如变形灵林谷的实测种子不要求玩家按特定先后领取；详情见共享条件文章。

## 当前能力的边界

RT2 能组合个人条件与共同世界条件，但需要区分单个事件的个人变牌结果，以及跨来源的“变牌组合”编辑器：**多人变牌组合目前没有作为正式能力开放。** 不能用一个事件的共享结果推断整局所有变牌都已串联。

地图预测描述共同的标准地图；普通问号路线类别预测有单人等明确前提，见 [[event-appearance|事件出现性]]。这不代表 RT2 会模拟整桌之后的所有行动、牌组和路线历史。

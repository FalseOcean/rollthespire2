# RolltheSpire2

[English](README.md) · 简体中文

**找到想玩的种子，提前看看它会带来什么。**

RolltheSpire2（RT2）是《杀戮尖塔 2》的游戏内筛种与种子分析 Mod，也提供水晶球助手。你可以按想玩的条件找种子，查看已有种子的预测结果，或在遇到水晶球时规划怎么翻格。

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3755166888) · [GitHub 下载最新版](https://github.com/FalseOcean/rollthespire2/releases/latest)

在 Windows 上，同一份 RT2 会为游戏正式版 **0.111.1** 和测试版 **0.114.0** 自动选择对应规则。

**RT2 1.4.12**　优化筛种性能，并将常用参数集中到筛种页右侧的「搜索设置」中。

## 筛种

想找特定的涅奥开局、遗物和卡牌组合，或满足要求的商店、事件和地图？直接在游戏里组合条件，让 RT2 搜索符合要求的种子。

支持单人和 **2–4 人**筛种。多人可以一键读取当前大厅，也可以手动配置队伍，为各席设置个人条件，并为整队设置共享条件。

RT2 会根据查询和设备选择 CPU 或 GPU。搜索时可以查看条件的大致稀有度、实时速度，以及能够估计时找到一个结果所需的时间。常用条件可以存成预设，下次直接复用。

在筛种页选择单人或多人，设置角色、进阶和想要的条件，然后开始搜索。点击右上角的「搜索设置」，可以调整目标结果数量、CPU／GPU 模式、执行顺序、GPU 批次上限、CPU 线程数和搜索起点。

想关掉面板后继续筛种，可以在 RT2 的全局设置中开启「启用持久筛种」。从游戏主菜单开始搜索，关面板后会以较低负载继续。进入对局后，点击 RT2 图标可以查看进度和结果，也可以停止搜索。

## 种子分析

从搜索结果打开**种子分析**，或直接输入已有的种子，查看开局选项、地图、商店、事件和战斗奖励等预测。想留着以后再玩，可以把种子连同配置和备注一起存进资料库。

## 水晶球助手

在 RT2 设置中开启「显示局内工具入口」。遇到水晶球时，点击对局右上角的骨骰图标。助手可以读取当前事件状态，让你选择想拿的奖励、比较金币方案，并查看对应的翻格指引。

## 安装与使用

### Steam 创意工坊

1. 打开 [RolltheSpire2 工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3755166888)，点击**订阅**。
2. 等 Steam 下载完成，再启动游戏。如果游戏正在运行，请退出后重新启动。
3. 在游戏主菜单打开 **Mods（模组）**，启用 **RolltheSpire2**。如果游戏提示重启，按提示操作。
4. 回到主菜单，点击左上角的 **RolltheSpire2** 入口。

### 从 GitHub 手动安装（Windows）

1. 退出游戏。打开 [GitHub 最新发布页](https://github.com/FalseOcean/rollthespire2/releases/latest)，在 **Assets** 中下载 `RolltheSpire2-版本号.zip`。带 `-source` 的 ZIP 和 `Source code` 都是供编译用的源码包。
2. 在 Steam 库中右键《杀戮尖塔 2》，选择**管理 → 浏览本地文件**。在打开的游戏安装目录中找到 `mods` 文件夹。如果没有，就新建一个。
3. 解压安装包，把里面的 `RolltheSpire2` 文件夹放进 `mods`。打开 `mods/RolltheSpire2` 后，应能直接看到 `RolltheSpire2.dll` 和 `RolltheSpire2.json`。
4. 启动游戏，在主菜单的 **Mods（模组）** 中启用 **RolltheSpire2**。按游戏提示重启后，即可从主菜单左上角打开 RT2。

工坊安装由 Steam 更新。手动更新时，先退出游戏，再用新版文件夹替换 `mods` 下的旧版。切换安装方式时只保留一份 RT2。改用工坊就把手动安装的文件夹移出 `mods`，改用手动安装就先取消工坊订阅。

### 复用预设和搜索历史

在「资料库 → 预设搜索」打开预设，点击「复制分享码」。收到分享码后，复制并点击「从剪贴板导入」，即可预览、使用或保存。分享码只携带队伍、进阶和生效的筛选条件。多人按原角色顺位和各席条件搜索，所有席位按全解锁计算，在主菜单就能使用。

在「资料库 → 历史搜索」选中旧记录，点击「重载并校验已有结果」。RT2 会载入原条件，按当前环境逐个检查已保存的种子。结果可直接预测或收藏。原搜索记录和扫描位置保留。

## 使用前请了解

- 多人预测按大厅席位对应各位玩家。换人或换席后，请重新读取大厅。部分预测会受实际选择或领取顺序影响，具体规则可查阅游戏内百科。
- 游戏更新，以及修改随机数、卡池、事件或奖励规则的其他 Mod，都可能影响筛选和预测结果。单人和多人支持的条件也有所不同。
- 搜索速度随条件和设备变化，稀有度与预计时间均为估算。开启未校验候选后，返回的候选可能不满足条件。开启地图有损快筛后，可能漏掉符合条件的种子。

## 问题反馈

遇到崩溃、搜索失败、异常掉速或预测错误时，请在 RT2 顶部打开**问题反馈**并导出诊断 ZIP。打开预填环境信息的 Issue 页面，补充问题描述与复现步骤，手动附上 ZIP 再提交。Issue 和附件是公开的，请在上传前检查内容。也可以将诊断 ZIP 和问题描述发送至 **rollthespire2@outlook.com**。[提交 GitHub Issue](https://github.com/FalseOcean/rollthespire2/issues/new)

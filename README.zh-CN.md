# RolltheSpire2 1.2.0

[English](README.md) | 简体中文

一个面向《杀戮尖塔 2》的游戏内筛种与种子预测 Mod。这是冻结保留的 **1.2.0** 源码快照，目标环境为 **Windows、游戏 0.111.0**，不再持续维护。

## 功能

- 按需要的开局条件筛种，查看种子的预测结果。
- 筛选涅奥、商店、遗物、战斗奖励、Boss、先古及支持的事件结果。
- 在支持的条件下使用 CPU／GPU 搜索，显示稀有度和搜索时间估算。
- 提供中英文界面及筛种预设。

本版早于 1.3.0 的新界面、多人使用流程、百科与种子收藏版本。游戏更新或其他 Mod 可能影响预测准确性；概率与时间为估算值。

## 安装

从对应 GitHub Release 下载 `RolltheSpire2-1.2.0.zip`。关闭游戏，将其中的 `RolltheSpire2` 文件夹放入游戏的 `mods` 目录。文件夹只需 Mod DLL 和 manifest，不需要 PCK。避免同时加载工坊版与手动安装的重复副本。源码 ZIP 需先编译。

从游戏主菜单打开 RolltheSpire2。[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3755166888)提供当前工坊版本，可能与此历史版本不同。

## 源码与反馈

构建步骤见 [BUILDING.md](BUILDING.md)，其中的命令禁用游戏目录部署。源码不包含游戏 DLL。可在工坊留言，或邮件联系 rollthespire2@outlook.com；请附种子、筛选条件、游戏／Mod 版本和相关日志。

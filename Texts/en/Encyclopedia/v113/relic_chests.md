# Relics in Treasure Rooms

Even in single-player, chests use separate **shared relic bags**. Opening a chest rolls Common, Uncommon, or Rare to decide which bag to look in first, then draws from the front. A Rare roll still leaves the question of which eligible Rare relics are left in that bag. The personal Rare queue in [[relics]] comes from a different bag.

You've opened the first chest. Why can taking or skipping the relic change the second chest? The relic already came out of the bag when you opened it. In single-player, claiming it uses another treasure RNG draw. Skipping leaves that draw for later, so the second chest can start from a different position in the stream. RT2 calculates the sequence with earlier chest rewards claimed.

## Filtering the First Two Chests

Switch to chest filtering on the Relics page to check the first chest, the second, or both. Count chests in **actual encounter order**, including question marks that turn into treasure rooms. You can specify a chest or look for the target anywhere within the selected range. An empty slot adds no requirement.

If you already got the target from the same qualifying Neow opening, that counts toward obtaining it. The result shows the actual opening source. If {{relic:SILVER_CRUCIBLE}} leaves a chest without a relic, that empty chest still takes a position.

The filter uses normal, non-tutorial single-player relic eligibility before floor 41 and accounts for relics actually obtained at the opening. If another source takes a relic out of the shared bags along the way, later chests can change.

## The Nine-Entry Initial Reference

The nine entries in Seed Information also assume each chest reward is claimed and use eligibility before floor 41. They start with the untouched shared bags. Use them to see a seed's initial opportunities. For the first two chests after a chosen opening, use chest filtering.

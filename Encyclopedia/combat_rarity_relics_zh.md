# 战斗奖励：稀有牌与改变奖励的遗物

> 机制基准：Slay the Spire 2 Beta 0.111.0

普通战斗通常生成三张卡牌，先决定稀有度，再选择身份。奖励生成会记住此前的稀有度历史；部分遗物会增加奖励或改变生成规则。

## 稀有度修正

| 参数 | A0～A6 | A7+ |
| --- | --- | --- |
| 普通战斗基础稀有率 | 3% | 1.49% |
| 每张非稀有牌增加的修正 | +1% | +0.5% |
| 初始修正 / 出稀有牌后的重置 | -5% | -5% |
| 修正上限 | +40% | +40% |

实际稀有率为基础值加当前修正。开局修正为 -5%，因此普通稀有度判定开始时不能出稀有牌。每生成一张非稀有牌就增加修正，生成稀有牌则立即重置；一组三张牌内部也逐张更新，最后的修正继续带到下一组。

## {{relic-icon:PRAYER_WHEEL}} 与吃不完的糖

{{relic:PRAYER_WHEEL}} 在普通怪物战斗后多生成一整组三张卡牌奖励。额外一组同样读取并更新稀有度修正，也会继续消耗奖励随机数（Rewards），影响后续奖励。

{{relic-icon:LASTING_CANDY}} 按战斗卡牌奖励的间隔额外加入一张能力牌，使对应奖励从三张变成四张。额外能力牌使用基础稀有率：A0～A6 为 3%，A7+ 为 1.49%；**不读取也不更新普通稀有度修正**。即使普通三张暂时不能出稀有牌，它仍可能出稀有。它消耗奖励随机数，所以随机流的位置仍会改变。

## {{relic-icon:WHITE_BEAST_STATUE}} 与药水概率

普通药水掉落概率初始为 40%，失败后下次 +10%，成功后下次 -10%，并非每场独立的固定 40%。

{{relic:WHITE_BEAST_STATUE}} 直接保证药水奖励，跳过普通掉落判定。因此不消费那次判定随机，也不因强制掉落而把概率减 10%；随后仍要随机药水稀有度与身份。保证掉药水不等于保证指定药水。

## 哪些效果参与 RT2 查询？

奖励遗物必须在所选开局中实际获得。比如 {{relic-icon:SMALL_CAPSULE}} 抽到 {{relic:PRAYER_WHEEL}}，或经 {{relic-icon:NEOWS_BONES}} 获得 {{relic-icon:LARGE_CAPSULE}} 并抽到 {{relic:LASTING_CANDY}}，或扭蛋抽到 {{relic:WHITE_BEAST_STATUE}}。

最终核验沿着该开局，应用实际获得遗物的已建模奖励效果。仅要求某遗物出现在未来的遗物队列里，不代表战斗查询会当作已经持有。

单人提前筛选只计入条件明确指定的奖励影响：依靠未指定扭蛋遗物才满足战斗条件的种子，可能在最终核验之前漏掉。把所需扭蛋内容写进条件，可让这段前提参与提前筛选。当前多人筛选会重放实际扭蛋抽取，并计入所抽遗物的已建模持有效果，即使未逐件指定；领取即时效果另见 [[neow-capsule]]。

## {{card:THE_HUNT}} 的战斗条件

{{card:THE_HUNT}} 完成击杀并触发效果时会额外增加一组三张卡牌奖励，但是否抽到、打出并完成击杀取决于实际战斗。RT2 当前不模拟战斗过程，不会仅因卡组里有这张牌，就把每场额外奖励计入查询。

# 变牌事件：保留约定的初始牌

RT2 的事件变牌条件预测的是**约定初始牌被抽成哪张牌**。到达时的完整牌组可以不同，但你必须仍有合法的初始打击 / 防御等目标，实际选择它们，并保持预测所用的变牌池与相关规则。

## 当前提供的变牌分支

| 事件 | 约定变牌数量与选择 |
| --- | --- |
| 共生体 | 选择变牌分支，变化一张初始牌 |
| 混沌芳香 | 选择放手分支，变化一张初始牌 |
| 低语空谷 | 选择拥抱分支，变化一张初始牌 |
| 变形灵林谷 | 选择双变牌分支，变化两张初始牌 |
| 审判 | 接受后抽到无名者案件，并选择无罪分支，变化两张初始牌 |

两张结果可以要求包含目标牌，也可以要求组成指定组合。组合检查不要求两张结果固定先后，但不同来源牌的变牌池可能不同；不能随意把一张新获得的牌替代约定初始牌。

## 结果怎样生成

这些分支使用事件自己的随机。RT2 会先重放事件内部必要步骤：例如低语空谷先随机计算金币变量，审判先抽案件，然后才抽变牌结果。普通战斗奖励或商店随机不会直接推进这条事件随机。

目标牌来源、解锁、模式和相关效果可能改变合法变牌池。额外游戏效果或模组改动若改变事件随机、第二张目标或候选池，也会改变预测前提。结果条件关注抽出的卡牌身份，不同时保证入组后的升级、附魔或其他修改。

## 多人中的变形灵林谷

变形灵林谷是多人共享事件，玩家通过共同选项机制选择分支；各玩家的事件随机起点不加入席位差异。相同角色、输入牌、实际处理次序、变牌池和相关效果一致时，可以得到相同结果。普通非共享事件的随机起点则包含玩家席位。

这里的“处理次序”指游戏实际依次处理所选牌的顺序，不能仅凭点选先后推断。两张约定初始牌使用同一变牌池时，可以按结果组合理解。多人实测例见 [[multiplayer-shared|多人共享条件]]。

这些都是以事件发生和实际选牌为前提的结果预测。它们不会证明事件可达，或保证初始牌能沿路线保留到这里。

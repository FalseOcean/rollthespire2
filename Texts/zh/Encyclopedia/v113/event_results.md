# 事件结果能筛什么？

想在玩偶室拿到某尊娃娃，可以先用种子和席位算出会看见哪几尊。许多事件都有自己的随机流，像这样的结果可以在进场前筛出来。事件排在哪里、当时有没有资格进场，另见 [[event-appearance|事件出现性]]。

| 事件 | 可以指定的结果 |
| --- | --- |
| 色彩哲学家 | 最初给出的颜色里有没有目标角色 |
| 假商人 | 六件库存中有没有指定假遗物，位置不限 |
| 垃圾堆 | 选卡牌或选遗物分别能拿到什么 |
| 审判 | 接受审判后遇到的案件，入场编号只是装饰 |
| 造卡工坊 | 提供的卡牌类型，以及选定类型后可选的附加效果 |
| {{event:DOLL_ROOM}} | 无伤随机拿走哪一尊，或扣 5 生命的二选一里有没有目标 |
| {{event:MUSEUM_OF_TORTURE}} | 从三件候选中展示哪件遗物，拿走时还会得到一张随机诅咒 |
| {{event:THERMAE_NONUPEIPE}} | 九件候选里，喝浴池水会拿到哪件遗物 |
| {{event:CRYSTAL_SPHERE}} | 能翻到的指定卡牌，或遗物奖励掷出的稀有度 |

色彩哲学家、假商人和垃圾堆的候选与概率见 [[event-stable-results|稳定事件结果]]。水晶球的目标与翻格规则另见 [[crystal-sphere|水晶球]]。

像遗物交换商这样的事件，会先掷普通、罕见或稀有，再从遗物袋里找一件。这里筛的是**掷出的档位**，具体抽到哪件还要看袋里剩什么。可选的事件有训练假人、冷光合唱团、长者兰伟德、遗物交换商、圆桌茶会、这个还是那个、无休之处、审判和明显有秘密的瀑布。要走能拿遗物的对应分支，比如训练假人要选第 3 档并在限时内获胜。一条分支有多次掷取时，可以指定第几次，也可以要求任一次或每一次都掷中这个档位。交换商有三个报价，实际只成交一项。

想找的是变牌后的牌，则可以筛共生体、混沌芳香、低语空谷各一次，或变形灵林谷、审判对应选项各两次。RT2 按到场后选择合法初始牌来算，同一变牌池内也可以用角色专属初始牌。各事件的分支与目标见 [[event-transform-results|事件变牌]]，想合计多个来源则用 [[transform|变牌组合]]。

# {{relic:KALEIDOSCOPE}}：两组跨角色卡牌

{{relic-icon:KALEIDOSCOPE}}在开局生成**两组卡牌奖励**，每组从三个其他角色的卡池中各生成一张，玩家每组至多领取一张，也可以跳过。原版中，全部角色卡池解锁后它才有资格出现在涅奥选项或骨骰中。

## 卡牌怎样生成

每组先用 **Niche RNG** 打乱其他角色卡池并选取三个，再用玩家的 **Rewards RNG** 生成卡牌：先决定稀有度，再从对应角色、对应稀有度的卡池中抽牌。两组都在奖励界面出现之前生成。若此前的骨骰遗物使用了这两种随机状态，必须从推进后的状态继续计算。共同原理见 [[why-predictable]]。

指定金卡需要同时满足“选中角色池 → 判定稀有 → 抽中具体卡牌”。普通生成规则的基础稀有率在 A0–A6 是 **3%**，A7+ 是 **1.49%**；这不是所有奖励来源在所有状态下都固定采用的概率。要求两张指定金卡还要满足两组的领取限制，可能非常稀有，但每个 Seed 的检查仍是一段短重放。

## 怎样填写筛选

RT2 可以指定卡牌，并按需区分两组的顺序。两张目标必须能分别从两组中领取，不能把同一组里同时看见的两张牌都算作获得。

**条件中指定的牌按实际领取处理，未指定的组按跳过处理。** 例如只指定一张牌，就是领取这张牌并跳过另一组；RT2 不会自动替你任选另一张来改善后续结果。若之后有{{relic:WHETSTONE}}或{{relic:WAR_PAINT}}，选牌造成的牌组变化可能进一步影响骨骰最终诅咒，见 [[neow-bones-curse]]。
